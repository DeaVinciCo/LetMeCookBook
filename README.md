# Let Me Cook! Book

A digital cookbook organizer for keeping recipes together and easy to use across your devices.

## Try it online

Open the web app: **[letmecookbook.web.app](https://letmecookbook.web.app)**

The web app can be installed like an app:

- **iPad/iPhone:** open the site in Safari, tap **Share**, then **Add to Home Screen**.
- **Android:** open the site in Chrome, then use **Install app** or **Add to Home screen** from the browser menu.
- **Windows:** open the site in a supported browser, or use the Windows installer below.

## Sync and data

The hosted web app supports Google sign-in and recipe sync through Firebase. Desktop and Android native installs currently store data locally and do not sync through that cloud service. Use the app's backup/export and restore/import features to move data between those editions. Keep your own backups of important recipes.

## Platform notes

- The web app is available at the link above and can be added to a device's Home Screen.
- The Android APK is a debug-signed sideload build, not a Google Play Store release.
- iPad and iPhone users can install the web app as a PWA. A native iOS installer is not provided.
